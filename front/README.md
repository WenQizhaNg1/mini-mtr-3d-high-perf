# 前端与图层工作台

仓库根目录运行 `npm run dev`，默认 http://127.0.0.1:8080 。首页为 `/`，工作台为 `/workbench`，首页右上角有入口。

## 启动与权限

1. 后端根目录 `.env` 配置 `WORKBENCH_TOKEN`，然后重启 `npm run server`。留空时不能导入或保存。
2. 初次启用 V7 函数源执行 `docker compose restart martin`；后续导入无需重启。
3. 工作台输入同一个令牌。令牌仅保存在页面内存中，刷新或离开页面后清除，不保存到 localStorage。

开发环境 `/api` 代理至 Java 3002。在 `front/.env` 设置 `API_PROXY_TARGET` 可改目标；Vite 保留 Host，让写请求按同源处理。生产服务需将 `/api` 反向代理至 Java，正确保留外部 Host/协议；页面路由回退到 index.html。不要将 WORKBENCH_TOKEN 放入 VITE 环境变量或前端构建产物。

`VITE_TRAIN_API_URL` 可覆盖首页交通/样式读取地址，默认留空使用同源代理。工作台 API 始终走同源 `/api`。瓦片、字体、精灵地址来自后端 `MARTIN_PUBLIC_URL`，前端无需配置 Martin 地址。

## 操作

- 数据集：选文件 → 字段检查 → 语义类别、几何列和属性映射 → 声明 WGS84 → 校验并预览 → 创建草稿 → 发布。
- 导入弹窗显示最多 10 个样例的交互地图。修改输入后需重新校验；CSV 属性不自动猜测类型。
- 图层：选择、新建或复制方案；从已发布源添加点、线、面、挤出或标签图层，支持排序、隐藏、复制和删除。
- 常用控件修改字面量。表达式通过高级 JSON 修改，不会被普通控件覆盖；JSON 未应用或 MapLibre 校验失败时禁止保存。
- 编辑首先进入本地草稿。保存后重新读取服务器完整 style.json；离开、切换方案或刷新时提醒未保存修改。
- 首页按系统明暗偏好加载 mtr-light/mtr-dark。自建方案可独立预览；若要在首页展示新图层，将它加入相应首页方案并保存。

底图仅选择现有方案。工作台列车为静态示意要素，不启动 SSE。首页继续播放后端轨迹；列车几何尺寸仍由现有生成代码控制，修改轨道线宽不会自动改变车辆宽度。

暂不提供几何编辑、覆盖导入、删除数据集、历史版本或多用户权限管理。

## 验证

`npm --prefix front test` 运行样式组合测试；`npm run build` 检查 TypeScript 并打包。浏览器验收覆盖导入/发布/保存/刷新、JSON 错误、未保存保护、令牌生命周期、首页自定义源及列车选中。
