# 地图图层样式

2026-09-05：参考 Mini Tokyo 3D 的鲜明线路、白心站点和粗无衬线标签，使用 MapLibre 原生图层实现。保留原版非地图卡片，不引入 deck.gl 或 Three.js。

## 实现

- `front/src/map.ts`：宽线路、细浅色衬边、换乘站放大、Noto Sans CJK SC Bold 站名；日夜文字与描边分别配色。
- `front/src/train-geometry.ts`：后端坐标和朝向转为 Mercator 平面矩形，再交给 `fill-extrusion` 挤出。保留列车 ID 和业务属性。
- zoom 14 时线路宽 10 像素，列车示意尺寸为 32.5 × 10 地图像素、高 7.5 像素对应的地面米数。线路宽度、衬边与列车长宽高统一按每放大一级乘 √2 连续缩放，缩小时同步变小；不再保持近似固定的列车屏幕尺寸。它不是实际车厢尺寸，也不含模型、车窗或投射阴影。
- 车体略提亮，侧面由 MapLibre 光照区分；选中变黄。点击、详情锚点、1 秒位置/最短角度补间保持原接口。弹窗仍锚定地面中心。
- 正常最多 30 次/秒更新几何，省电最多 1 次/秒；暂停且缩放不变时不重复提交。轨道、班次和实时匹配仍由后端负责。

## 验证与边界

几何测试覆盖方向、闭环、稳定 ID 和缩放边界。浏览器检查本地 Martin/API、固定回放数据、日夜主题、zoom 10.5/13.5/14、pitch 0/42/60、旋转、390px 窄屏，以及既有列车/站点点击和回放操作。截图位于 `front/test-results/map-*.png`。

共享走廊仍沿用真实 OSM route pattern：太子—油麻地、机场快线—东涌线局部存在宽线颜色遮挡。本轮没有用整线偏移改变位置关系。若要求每条线路在任意缩放均完整可辨，下一步应单独生成按共享区段组织的制图几何，并同步处理列车的显示位置；不能直接改后端定位用的轨道。

夜间旧 OSM Liberty 底图仍有部分缺失 sprite 警告。本轮验证不等同大规模列车性能压测。
