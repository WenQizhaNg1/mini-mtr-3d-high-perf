# 阶段 6：前端功能迁移

2026-09-05 实施，默认入口为 `front/`。

| 能力 | 实现 |
| --- | --- |
| 实时与回放 | SSE 实时快照；香港时间选择、拖动、暂停、1/2/5/15/60 倍速、返回实时 |
| 时间范围 | `/api/service-day` 提供实际回放范围及班次存在性；范围内空缺日期显示无班次提示 |
| 列车详情 | 点击选中、高亮、线路、终点、运行/停站、前后站及修正时刻、时刻偏移；车次消失后清除选中 |
| 站点详情 | 地图拾取站码，使用 `/api/network` 显示双语名称及所属线路 |
| 天气与运营 | 当前天气、警告、旧缓存提示、运营健康及线路事件、官方链接；回放时明确标为当前信息 |
| 本地界面 | 中英文自动检测与偏好保存、地图标签切换、关于信息、Esc 关闭、省电模式 |
| 地图 | MapLibre 原生图层、一秒视觉补间；省电降低位置刷新频率，隐藏页面停止绘制 |

`playback.ts` 负责浏览器播放状态。每个回放请求组最多包含一次列车查询与一次服务日查询；请求完成后调度下一帧，按耗时推进模拟时间。拖动、模式切换和卸载取消在途请求，并以版本号拒绝已过期响应。跳转不跨时间插值；正常推进使用视觉补间。HTTP 请求有 15 秒超时；回放失败暂停并显示错误，可重新播放或返回实时重试。

`api.ts` 仅包含 HTTP 访问及前端本地 `contracts.ts` 的 type-only DTO 引用。业务事实来自 Java API，几何来自 Martin。服务器继续按共享周期轮询，不随单个浏览器的回放模式改变。回放使用现有位置接口，并非实时偏移和运营事件的历史归档。

旧根目录 `src/`、AMap 数据抓取脚本、旧测试、Webpack/Jest 配置、旧 HTML/CSS 入口及相关依赖已移除。旧图片、字体及其许可保留；旧代码可从 Git 历史恢复。编辑器归阶段 7；事件气泡和地图/车辆视觉重做仍属于后续样式工作。

验证命令：

```sh
npm run build
npm run test:front
npm run test:server
npm run test:browser
```

使用 Node 24。前端状态测试覆盖过期响应、切换直播、卸载清理、暂停、倍速、边界停止和 HTTP 失败。浏览器测试使用本地 Chrome、Martin/API，以及已导入的 2026-09-04 班次；天气与事件响应在测试中固定，以覆盖失败缓存和不安全链接。测试启动独立的 8082 前端，包含桌面和 390px 窄屏截图。

本地实测 2026-09-04 08:00（香港时间）返回 112 列车。阶段 6 后发现当天班次未自动生成，已于 2026-09-05 补齐后端启动准备和跨日续接，实时列车恢复。Martin 底图存在部分缺失 sprite 警告，Vite 仍有大 chunk 提示，留待视觉与资源优化处理。

本轮检查：前端构建、2 项前端状态测试及 1 项完整浏览器交互测试通过；后端 24 项测试通过，2 项需要 `DATABASE_URL` 的数据库集成测试跳过。数据库结构和后端运行代码本轮没有修改。

## 界面样式回迁（2026-09-05）

从 Git 历史中的 `assets/style.css` 和 `src/ui/*` 回迁非地图界面样式。复用原版昭源宋体、点阵宋体资源，以及卡片透明度、12px 模糊、扫描线、阴影、按钮、警告标签、时钟、时间轴和关于弹窗的 CSS 参数。

- 左上角恢复时间、日期、天气、实时状态的紧凑结构；点击状态行展开运营详情。
- 底部恢复播放图标、实时按钮、循环倍速、省电和语言按钮，以及逐小时刻度、三小时标签的当前服务日时间轴。
- 多日期回放保留在时间轴右侧 `⋯` 展开区域，时间范围仍来自后端。
- 列车/站点恢复黑底、线路色条/色块和宋体提示，随选中对象和地图移动；新增详情收进展开项。
- 右下角恢复圆形关于按钮和原作者说明弹窗。编辑器不在本轮范围。

地图底图、线路、站点和车辆的图层样式没有调整。窄屏采用必要的宽度与间距适配；状态展开项和日期入口属于新接口适配，因此不宣称整页逐像素一致。

验证包含实际字体加载、原版关键 CSS 参数、实时/回放交互、详情定位、关于弹窗，以及桌面/390px 窄屏截图。截图由 `npm run test:browser` 输出到 `front/test-results/`。
